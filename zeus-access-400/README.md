# zeus-access-400

> **Legacy notice:** This project is no longer actively developed in this location.

The active successor project is:

https://github.com/gzeuner/zeus-ibmi-extract-transform

## Status

`zeus-access-400` was originally created as a small Java CLI utility for selecting data via JDBC and exporting/transformation of query results.

Future development, modernization, maintenance and architectural cleanup will continue in the new standalone project:

**zeus-ibmi-extract-transform**

This legacy folder remains available for:

- historical reference
- migration comparison
- understanding the original implementation
- validating behavior against the successor project

## Important note

Please do not start new development in this folder.

New features, fixes and documentation updates should target:

https://github.com/gzeuner/zeus-ibmi-extract-transform

## Long-term outlook

This legacy project may be removed from `RPG4J` in the future once the successor project has fully covered the relevant use cases.
